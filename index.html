Instructions

🎯 Getting Started

  • Select Algorithm: Choose from 7 different algorithms
  • Choose Preset: Start with a pre-built graph or create custom
  • Adjust Speed: Control visualization speed (1-100)
  • Start: Click Start or press Space

🖱️ Mouse Controls

  • Left Click: Create nodes (custom mode)
  • Right Click: Set start node
  • Shift + Right Click: Set end node
  • Ctrl/Cmd + Click: Toggle walls
  • Mouse Wheel: Zoom in/out
  • Alt + Drag: Pan canvas

⌨️ Keyboard Shortcuts

  • Space - Start/Pause
  • R - Reset
  • S - Step
  • Ctrl/Cmd + Z - Undo
  • Ctrl/Cmd + Y - Redo
  • Ctrl/Cmd + S - Export
  • F - Toggle Fullscreen
  • T - Toggle Theme

📱 Touch Gestures

  • Pinch: Zoom in/out
  • Two Finger Drag: Pan canvas
  • Tap: Select/Create nodes
  • Long Press: Set start/end nodes
